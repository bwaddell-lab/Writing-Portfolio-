How to Upload Tax Documents

User Guide Documentation Sample

Uploading accurate tax documents is an important step in completing and submitting a tax return. This guide explains how users can securely upload documents through the online tax portal.

Purpose

This guide helps users upload tax documents, verify successful submission, and troubleshoot common upload issues.

Before You Begin

  • Ensure you have access to your account credentials.
  • Verify that your internet connection is stable.
  • Locate the files you plan to upload.
  • Accepted file formats include PDF, PNG, JPG, and DOCX.

Supported Documents

  • W-2 Forms
  • 1099 Forms
  • Identification Documents
  • Business Expense Records
  • Tax Return Supporting Documents

Steps to Upload a Document

  1. Log into your account. Enter your email address and password on the login page.
  2. Open the Documents section. From the dashboard, select the “Documents” tab located in the navigation menu.
  3. Select Upload Document. Click the upload button to open the file selection window.
  4. Choose your file. Locate the file on your device and select Open.
  5. Review document details. Confirm the correct file was selected before submission.
  6. Submit the upload. Select Submit to securely upload the document.

Upload Confirmation

After submission, a confirmation message should appear indicating the upload was successful. Uploaded documents can also be viewed in the Documents History section.

Troubleshooting

File Upload Failed

Ensure the file size does not exceed the platform upload limit.

Unsupported File Type

Convert unsupported files into PDF format before attempting another upload.

Slow Upload Speeds

Large files or unstable internet connections may increase upload times.

Accessibility Notes

  • All buttons include keyboard navigation support.
  • Images and icons should include descriptive alt text.
  • Color contrast follows accessibility standards for readability.

Tips for Users

  • Use clear file names when uploading documents.
  • Upload one document at a time for easier tracking.
  • Verify uploaded files before completing your return.
