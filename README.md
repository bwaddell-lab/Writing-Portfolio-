 
# Finance Writing Portfolio

This project is a writing portfolio focused on explaining finance, and techinical concepts in clear language for everyday users.

## Purpose

The goal of this portolio is to demostrate my ability to take complex finance and techinical topics and turn them into simple easy to user stand content.
## Audience

This content is written for our less savvy techinical and financial friends. 


## Writing Samples

This portfolio will include a combination of technical and finical copy such as:

- What Is Investing?
- How Trading Apps Work
- How banking apps work
- What Happens When You Reset a Password
- Common Investing Terms Explained Simply
